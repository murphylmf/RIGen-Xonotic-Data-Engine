# RIGen construction code release licensing

This repository contains original RIGen code together with modified and upstream Xonotic components. The terms apply by component; there is no blanket license that relicenses upstream material.

## RIGen-authored material

RIGen-authored orchestration scripts, configuration templates, capture patches, validation tools, and documentation are provided for research reproduction. Unless a file or directory contains a more specific notice, preserve this file and `NOTICE` when redistributing those materials. The RIGen data and documentation layer is described separately in the data release license.

## Xonotic-derived material

Modified Xonotic, DarkPlaces, and gmqcc source remains under the applicable upstream GPL or project terms. The upstream notices and license texts are retained under `common_capture/licenses/` and in the source snapshots. This repository does not relicense those components.

## External dependencies

Python packages, FFmpeg, SDL/OpenGL, GPU drivers, Xonotic assets, maps, models, fonts, and other external dependencies retain their own licenses. Obtain them from their official sources and follow their terms.

## No warranty

The release is provided for reproducibility without warranty. The capture scripts expect a compatible local runtime, local assets, and machine-specific configuration.
